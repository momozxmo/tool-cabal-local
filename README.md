## v0.1.41 — เลือกช่อง Aztek แม่นยำขึ้น และสร้างบันเดิลต่อเนื่อง

- ปรับการเลือกช่องและปุ่มบน Aztek สำหรับ Item Code, Event และ Product
- มีปุ่ม “ตรวจเองครบแล้ว — สร้างทุกบันเดิลต่อเนื่อง” ยืนยันครั้งเดียวสำหรับคิวและเกมปัจจุบัน
- ผล Recheck ยังคงแสดงตามจริง ไม่เปลี่ยนผลที่ไม่ผ่านให้เป็นผ่าน และไม่อนุมัติส่งต่อให้อัตโนมัติ
- หากกรอกไม่ครบ บันทึกไม่สำเร็จ ผลไม่แน่นอน หรือไม่มีเลข Bundle โปรแกรมยังหยุดเพื่อป้องกันการสร้างซ้ำ
- ทดสอบอัตโนมัติ 2,749 รายการผ่าน และทดสอบโปรแกรมด้วยข้อมูลแยกแล้ว ไม่สร้างข้อมูลจริงบน Aztek
- [รายการเปลี่ยนแปลงและข้อจำกัด](docs/RELEASE_NOTES_v0.1.41.md)
- ผู้ใช้เลือกอัปเดตเมื่อพร้อม หลังอัปเดตควรตรวจเลขรุ่นและร่าง/คิวเดิมว่ายังอยู่ครบ

## v0.1.40 — ตรวจเองครบแล้ว สร้างทุกบันเดิลต่อเนื่อง

- เพิ่มปุ่มแยกพร้อมยืนยันครั้งเดียวสำหรับคิวและเกมปัจจุบัน ไม่เปิดโหมดถาวร
- ทำต่อเมื่อบันทึกสำเร็จและมี Bundle ID แม้ Recheck ไม่ผ่านครบ โดยเก็บผลตรวจจริงไว้
- ยังหยุดเมื่อกรอกไม่ครบ บันทึกไม่สำเร็จ ผลไม่แน่นอน หรือไม่มี ID; ปุ่มสร้างเดิมคงพฤติกรรมเดิม
- ไม่อนุมัติส่งผลที่ไม่ผ่านไป Event/Product อัตโนมัติ และคงการป้องกันสร้างซ้ำ
- ทดสอบ full 2,113 รายการผ่าน และตรวจแพ็กเกจด้วยข้อมูลทดสอบแยกผ่าน
- [รายการเปลี่ยนแปลงและข้อจำกัด](docs/RELEASE_NOTES_v0.1.40.md)
- กด “อัปเดตโปรแกรม” → “ตรวจอัปเดต” → “อัปเดต” เมื่อพร้อม; ไม่ติดตั้งทับให้เอง

## v0.1.39 — ปรับการเลือกและแก้ไขข้อมูล Bundle

## คุณสมบัติของเวอร์ชัน Local

- เปิด Item Finder ในเว็บ local ให้อัตโนมัติ
- ไม่มีหน้าล็อกอินของ All for Cabal
- server ฟังเฉพาะ `127.0.0.1:8000`
- เก็บฐานข้อมูลและ config ไว้ที่ `%LOCALAPPDATA%\AllForCabalWeb`
- ติดตั้งทับหรือถอนโปรแกรมแล้วข้อมูล Local ยังอยู่
- รวม Chromium ที่ระบบอัตโนมัติต้องใช้ไว้ใน Setup แล้ว
- เชื่อม Aztek แบบ Local ผ่าน Chromium ที่โปรแกรมเปิดให้ โดยไม่เก็บรหัสผ่าน IPA/Aztek
- รองรับปุ่ม `สร้าง Bundle` ของ Aztek v2 และชื่อปุ่มแบบเดิม
- อ่านบล็อกรางวัลต่อเนื่องที่ไม่มีหัวตาราง Item Kind ซ้ำ และส่ง Item Code หลายรายการได้ครบ
- Controller ปิด server และตัวโปรแกรมได้โดยไม่ค้างอยู่ที่ข้อความกำลังปิดโปรแกรม
- ตั้งแต่ v0.1.31 สามารถตรวจและติดตั้งเวอร์ชันถัดไปจากในโปรแกรมได้

อ่านขั้นตอนทั้งหมดได้ที่ [คู่มือติดตั้ง](docs/LOCAL_INSTALL.md)

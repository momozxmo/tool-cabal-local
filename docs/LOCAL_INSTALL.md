# คู่มือติดตั้ง All for Cabal Web แบบ Local

## 1. ดาวน์โหลดและตรวจไฟล์

ดาวน์โหลดสองไฟล์จาก [Release v0.1.33](https://github.com/momozxmo/tool-cabal-local/releases/tag/v0.1.33):

- `All.for.Cabal.Web.Setup-0.1.33.exe`
- `All.for.Cabal.Web.Setup-0.1.33.exe.sha256`

เปิด PowerShell ในโฟลเดอร์ Downloads แล้วใช้คำสั่ง:

```powershell
Get-FileHash ".\All.for.Cabal.Web.Setup-0.1.33.exe" -Algorithm SHA256
Get-Content ".\All.for.Cabal.Web.Setup-0.1.33.exe.sha256"
```

ค่าที่ถูกต้องคือ:

```text
1C8912D63A70854D3255239D3ADBA370B89AC86B95BF750C698046D4A19E417A
```

ถ้าค่าไม่ตรง ห้ามเปิด Setup และให้ดาวน์โหลดไฟล์ใหม่

## 2. ติดตั้งและเปิดโปรแกรม

1. ดับเบิลคลิก `All.for.Cabal.Web.Setup-0.1.33.exe`
2. ติดตั้งตามขั้นตอนปกติ
3. เลือกสร้างไอคอน Desktop ได้ตามต้องการ
4. หน้าสุดท้ายปล่อยเครื่องหมาย `เปิด All for Cabal Web` ไว้ แล้วกด Finish

Controller จะเปิด Item Finder ที่ `http://127.0.0.1:8000` ให้อัตโนมัติ โดยไม่ถามชื่อผู้ใช้หรือรหัสผ่านของ All for Cabal

Controller มีสามปุ่ม:

- `เปิดหน้าเว็บ` เปิดแท็บใหม่โดยใช้ server เดิม
- `เริ่มใหม่` หยุดและเริ่ม local server ใหม่
- `ปิดโปรแกรม` หยุด server และปิด Controller

## 3. เชื่อม Aztek

เปิดหน้า `เชื่อม Aztek` แล้วกด `เปิด Aztek และเชื่อม` โปรแกรมจะเปิด Chromium ให้ จากนั้นล็อกอิน IPA และ Aztek ด้วยตนเอง เมื่อเข้า Aztek สำเร็จโปรแกรมจะบันทึก Session สำหรับงานค้นหา Preview และสร้างข้อมูล โดยไม่ถามหรือเก็บรหัสผ่าน IPA/Aztek

หากเชื่อมไม่สำเร็จหรือหมดเวลา Session เดิมที่มีอยู่จะไม่ถูกลบทิ้ง สามารถกดเชื่อมใหม่ได้ภายหลัง

การเชื่อม Aztek, Preview และการส่งคำสั่งไป Aztek ต้องใช้อินเทอร์เน็ต

## 4. ข้อมูลและการอัปเดต

ข้อมูล Local อยู่ที่:

```text
%LOCALAPPDATA%\AllForCabalWeb
```

ปิด Controller ก่อนสำรองข้อมูล แล้วคัดลอกทั้งโฟลเดอร์นี้ได้ตามต้องการ

ตั้งแต่ v0.1.31 โปรแกรมมีปุ่ม `อัปเดตโปรแกรม` ที่มุมล่างขวาของหน้าเครื่องมือ
เมื่อมี Release ใหม่จะแสดงรุ่นและรายการแก้ไข ผู้ใช้เลือกกดอัปเดตเองได้ โปรแกรมจะ
ดาวน์โหลด Setup เต็ม ตรวจไฟล์ เก็บร่าง/คิว ปิด ติดตั้ง และเปิดกลับอัตโนมัติ
หากมีงานกำลังทำให้รอจนจบแล้วกดใหม่ การกด `ไว้ก่อน` จะไม่เริ่มติดตั้ง

หากเห็นคำเตือนเรื่องไฟล์หรือหน้า Aztek ที่ค้าง ให้ตรวจให้เรียบร้อยก่อนยืนยัน
โปรแกรมจะไม่กดบันทึกหรือสร้างข้อมูล Aztek ระหว่างอัปเดต ถ้าติดตั้งไม่สำเร็จ
ตัวช่วยจะแสดงสาเหตุและปุ่ม Retry ข้อมูล Local อยู่ที่เดิมและไม่มี rollback อัตโนมัติ

ผู้ใช้รุ่นก่อน v0.1.31 ต้องติดตั้ง Setup รุ่นนี้เองหนึ่งครั้งก่อน จึงจะใช้ระบบอัปเดต
ภายในโปรแกรมกับเวอร์ชันถัดไปได้

การถอนการติดตั้งจะลบเฉพาะไฟล์โปรแกรม ส่วนฐานข้อมูล, config และ backup จะยังอยู่ หากต้องการลบข้อมูลถาวร ให้สำรองข้อมูลก่อนแล้วลบโฟลเดอร์ข้างต้นด้วยตนเอง

## 5. v0.1.33 — Import Bundle จาก Excel และก็อปวาง

หน้า Bundle มีปุ่มดาวน์โหลด Template Excel สำหรับ Item ID บน Aztek ที่มีอยู่แล้ว
หัวชุดใช้ชื่อบันเดิลและประเภท ส่วนรายการใช้ Item ID / จำนวน / Rarity / เรทสุ่ม
ก็อปคอลัมน์ A:D มาวางได้โดยไม่ต้องพิมพ์ตัวคั่นเอง หรือเลือกไฟล์และ Sheet เพื่อพรีวิวก่อนเพิ่มเข้าคิวเดิม

รองรับ FIXED, CHOICE และ RANDOM รวมถึง Currency โดย RANDOM ต้องมีเรททุกแถวรวม 100%
ชื่อที่ชนกับคิวเดิมจะเติมเลขท้ายให้เห็นในพรีวิว Item ID ซ้ำข้ามบันเดิลได้
Import ไม่ตรวจว่า ID มีอยู่จริงและไม่สร้างข้อมูลบน Aztek อัตโนมัติ

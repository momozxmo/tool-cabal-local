# v0.1.43 — สร้างและตรวจ Item ก่อนนำไปจัด Bundle

เพิ่มหน้า **New Item — เตรียมรายการและตรวจผล** สำหรับ CABAL PC TH/SEA และ CABAL M TH/SEA

## วิธีใช้งาน

1. นำเข้า Excel โดยเลือก Sheet หรือส่งเฉพาะรายการที่ Finder หาไม่พบมาเป็นร่าง
2. ตรวจชื่อและคุณสมบัติ เติมช่องที่ขาด แล้วบันทึกและยืนยันร่าง
3. ค้น Item เดิมก่อน เลือกใช้ ID ที่มีอยู่ หรือเลือกสร้างใหม่และยืนยันเกม/จำนวนอีกครั้ง
4. โปรแกรมอ่านข้อมูลที่บันทึกกลับมาเทียบต้นฉบับ ส่งเฉพาะผลผ่านที่เลือกไป Finder แล้วเลือกส่งต่อ Bundle เอง

แค่นำเข้าหรือเปิดพรีวิวยังไม่สร้างข้อมูลจริง หากข้อมูลไม่ตรง อ่านไม่ครบ หรือยังยืนยันการสร้างไม่ได้ โปรแกรมจะหยุด ไม่กดสร้างซ้ำให้

## สิ่งที่เพิ่ม

- PC TH/SEA ใช้ GENERAL หรือ CABALPC_PREMIUM; M TH/SEA ใช้ GENERAL
- แนบรูปให้ร่างในเครื่องได้ และแสดงขอบเขตตรวจรูปแยกจากผลตรวจคุณสมบัติ
- รวมรายการที่ค่าที่ใช้สร้างเหมือนกันทั้งหมดได้ โดยรักษา Amt และแถวอ้างอิงของแต่ละ Bundle
- เก็บ Item ID และประวัติแต่ละรอบ การรับทราบปัญหาไม่เปลี่ยนผลให้ผ่าน
- กู้ ID ได้เฉพาะเมื่อมีคำตอบเดิมที่โปรแกรมเก็บและผูกกับรายการนั้นไว้ หากหลักฐานหายทั้งหมดต้องคงสถานะยังยืนยันไม่ได้ ไม่เดา ID จากชื่อ

## การตรวจและข้อจำกัด

ทดสอบอัตโนมัติ3,108กรณีผ่าน มีคำเตือนเดิม1รายการ ตรวจเกณฑ์22ข้อ แพ็กเกจ และการเปิดโปรแกรมด้วยข้อมูลทดสอบแยกแล้ว ไม่สร้างข้อมูล Aztek เพิ่มในการตรวจแพ็กเกจ

ไม่อ้างว่าทดสอบทุกหน้า/ทุกกรณีบนระบบจริง: Premiumอ้างอิงฟอร์มและsourceที่ตรวจได้ ไม่ได้สร้างPremiumจริง; รูปตรวจว่ามีรูป ไม่รับรองภาพเหมือนกันระดับพิกเซล

## ดาวน์โหลดและอัปเดต

ดาวน์โหลด Setup และไฟล์SHA-256จากReleaseเดียวกัน ตรวจhashก่อนเปิดไฟล์ ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล

SHA-256 ของ Setup:

```text
609F98EFE3EBE0BEC5C8A762DD24F8B7731E079AC583CD8A288CC6A99135A3B3
```

ผู้ใช้เลือกระหว่าง “อัปเดต” กับ “ไว้ก่อน” ได้ตามเดิม หลังอัปเดตให้ตรวจเลขรุ่น0.1.43และร่าง/คิวของตัวเอง การตรวจรีลีสนี้ไม่ได้ติดตั้งทับหรือรับรองการอัปเดตจริงบนเครื่องผู้ใช้

# All for Cabal Web v0.1.39 — ปรับการเลือกและแก้ไขข้อมูล Bundle

- Item Finder แยก “ส่งเฉพาะที่เลือก” และ “ส่งทั้งหมด” พร้อมจำนวนรายการ; ไม่ส่งทุกไอเทมเมื่อผู้ใช้เลือกเพียงบางรายการ และคงการส่งไอเทมซ้ำที่อยู่หลาย Bundle
- เพิ่ม “Clear ข้อมูล” ในกล่องวางข้อมูลจาก Excel ล้างข้อความและพรีวิวในครั้งเดียว โดยไม่ลบคิว Bundle ที่เพิ่มไว้แล้ว
- Bundle RANDOM นำเข้าและแก้ไขเรต `0` ได้ทั้งไอเทมและ Currency; แยกศูนย์จากช่องว่าง และกรอกช่องเรทตาม ID บน Aztek
- แสดงชื่อ Currency ที่เพิ่มใน Bundle เต็มบรรทัด เช่น Alz/Force Gem/ชื่อ Player EXP ไม่แสดงเพียง Credit/Debit/Player EXP; รองรับชื่อยาวและจอเล็ก
- คง Bundle Recheck, ตัวเลือกเบราว์เซอร์ Launcher และการอัปเดตโดยผู้ใช้เลือกเอง

การนำเข้า RANDOM ยังต้องมีเรตรวม `100%` และไม่รับค่าติดลบ/เกิน 100/ทศนิยมเกิน 3 ตำแหน่ง
Document Reference ยังคงเอกสารต้นฉบับครบ หากส่งเพียงบางไอเทม Recheck อาจแสดงรายการขาดเมื่อเทียบกับเอกสารเต็ม

ผู้ใช้ v0.1.31 ขึ้นไปกด “อัปเดตโปรแกรม” → “ตรวจอัปเดต” → “อัปเดต” เมื่อพร้อม

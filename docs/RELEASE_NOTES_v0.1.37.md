# All for Cabal Web v0.1.37 — Bundle Recheck

- หลังสร้าง Bundle แต่ละรายการ อ่านข้อมูลที่บันทึกจริงบน Aztek แล้วตรวจ ItemKind, Option, Duration, Amount และความครบของรายการเทียบกับเอกสารต้นฉบับ
- ตรวจ Currency/EXP, Rarity และเรท RANDOM ตามข้อมูลอ้างอิงที่มี พร้อมแสดงตารางต้นฉบับ ค่าที่ส่งสร้าง และค่าที่บันทึกจริง
- คิวทำรายการถัดไปและส่งเลข Bundle ต่ออัตโนมัติเฉพาะผลที่ผ่านครบ ผลไม่ตรง ตรวจไม่สำเร็จ หรือตรวจได้บางส่วนต้องรับทราบและยืนยันแยก
- ตรวจซ้ำจาก Bundle ID เดิมได้โดยไม่สร้างซ้ำ ลองอ่านข้อผิดพลาดชั่วคราวได้รวมไม่เกิน 3 ครั้ง และหยุดให้เชื่อมใหม่เมื่อ session หมดอายุ
- กู้รายการที่สร้างแล้วหลังเปิดโปรแกรมใหม่ เก็บประวัติผลตรวจแต่ละรอบพร้อมสาเหตุที่อ่านไม่สำเร็จ และแก้เลขที่กรอกผิดแล้วตรวจใหม่ได้
- คงการแก้ช่องเรทสุ่ม RANDOM ของ v0.1.36

คิวเก่าหรือการนำเข้าด้วย Item ID ที่ไม่มีคุณสมบัติต้นฉบับครบจะขึ้น “ตรวจได้บางส่วน” และหยุดรอรับทราบผล หาก Aztek แสดงเพียงชื่อ Currency โดยไม่แสดงรหัส ระบบจะไม่อ้างว่าตรวจรหัสผ่านครบ

ผู้ใช้ v0.1.31 ขึ้นไปกด “อัปเดตโปรแกรม” → “ตรวจอัปเดต” → “อัปเดต” เมื่อพร้อม โปรแกรมเดิมจะเปลี่ยนหลังผู้ใช้กดอัปเดตเอง

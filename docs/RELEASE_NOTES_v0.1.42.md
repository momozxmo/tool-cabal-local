All for Cabal Web 0.1.42 — ตรวจ Bundle แม่นยำขึ้น และดูจุดที่ต้องแก้ง่ายขึ้น

มีอะไรเปลี่ยนบ้าง

- ลดการแจ้งว่า “ข้อมูลไม่ตรง” ผิดพลาด เมื่อไอเทมมีคุณสมบัติเหมือนกัน แต่ Rarity หรือเรทต่างกัน และรายการสลับลำดับ
- แยก “อ่านข้อมูลไม่สำเร็จ” ออกจาก “ข้อมูลไม่ตรง” พร้อมคำเตือนเมื่ออ่านไม่ครบ ไม่ถือว่าผ่านครบ
- เลือกดูเฉพาะแถวที่มีปัญหาหรือข้อมูลไม่ครบได้ ทั้งผลล่าสุดและประวัติ โดยไม่แก้ผลตรวจเดิม
- ปุ่ม “ตรวจเองครบแล้ว — สร้างทุกบันเดิลต่อเนื่อง” และการยืนยันส่งต่อยังใช้กติกาเดิม

ตรวจแล้วก่อนเผยแพร่

ทดสอบอัตโนมัติ 2,777 รายการผ่าน ตรวจไฟล์โปรแกรมที่แพ็ก และเปิดทดสอบด้วยข้อมูลกับเบราว์เซอร์แยกแล้ว โดยไม่ได้สร้างข้อมูลจริงบน Aztek

วิธีอัปเดต

กด “อัปเดตโปรแกรม” → “ตรวจอัปเดต” → “อัปเดต” เมื่อพร้อม
หากยังมีงานค้าง กด “ไว้ก่อน” ได้ หลังอัปเดตให้ตรวจว่ารุ่นขึ้นเป็น 0.1.42 และร่าง/คิวเดิมยังอยู่ครบ

ข้อควรทราบ

- ไม่รวมการแก้ WR ที่พักไว้ในรอบนี้ และไม่เพิ่ม New Item
- ยังไม่ได้ยืนยันการติดตั้งและข้อมูลหลังอัปเดตบนเครื่องของคุณจริง หรือทุกสถานการณ์บน Aztek จริง
- Setup ยังไม่มีลายเซ็นดิจิทัล Windows อาจแจ้ง Unknown publisher ให้ตรวจ SHA-256 จากไฟล์แนบก่อนติดตั้ง

# ติดตั้งส่วนขยาย All for Cabal — Aztek Session Bridge

ส่วนขยายนี้ทำหน้าที่เดียว: อ่านเซสชัน Aztek (คุกกี้ + localStorage) จากแท็บที่คุณ
ล็อกอินไว้ แล้วส่งไปให้เว็บ All for Cabal ผ่าน **รหัสจับคู่ (pairing token)** ที่ใช้
ได้ครั้งเดียวและหมดอายุใน 5 นาที ส่วนขยาย **ไม่อ่านและไม่ส่งรหัสผ่าน Aztek** ของคุณ

เป็นส่วนขยายส่วนตัว (โหลดแบบ unpacked) ไม่ต้องอัปลง Chrome Web Store

## ติดตั้งครั้งแรก

1. เปิด `chrome://extensions` ในเบราว์เซอร์
2. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `extension/` ของโปรเจกต์นี้
4. ปักหมุด (pin) ส่วนขยายไว้บนแถบเครื่องมือเพื่อกดได้สะดวก

## วิธีเชื่อมเซสชัน Aztek

1. เปิดแท็บ Aztek (`https://aztek-tools.combo-interactive.com`) แล้ว **ล็อกอินให้เรียบร้อย**
   ปล่อยให้แท็บนี้เป็นแท็บที่เปิดอยู่ (active)
2. เข้าเว็บ All for Cabal → หน้า **`/account`** → กดสร้าง **รหัสจับคู่** แล้วคัดลอก
   (รหัสมีอายุ 5 นาที ใช้ได้ครั้งเดียว)
3. กดไอคอนส่วนขยาย → วางรหัสจับคู่ในช่อง แล้ว (ถ้าต้องการ) ใส่ชื่อบัญชีกำกับ
4. กด **เชื่อมต่อ** — ถ้าสำเร็จจะขึ้น "เชื่อมต่อสำเร็จ" และช่องรหัสจะถูกล้าง
5. กลับไปที่หน้า `/account` จะเห็นสถานะเปลี่ยนเป็น **เชื่อมแล้ว**

เมื่อเซสชัน Aztek หมดอายุ ให้ล็อกอิน Aztek ใหม่ในแท็บ แล้วทำขั้นตอน 2–4 ซ้ำ

## ชี้ส่วนขยายไปยัง backend ตัวจริง (deploy)

ค่าเริ่มต้นชี้ไปที่เซิร์ฟเวอร์ dev บนเครื่อง (`http://localhost:8000`)
เมื่อ deploy ขึ้น Render ให้แก้ backend origin ดังนี้:

1. เปิดไฟล์ `extension/config.js` แล้วเปลี่ยนค่า `BACKEND_ORIGIN` เป็น URL ของ Render
   เช่น `https://all-for-cabal.onrender.com`
2. เปิด `extension/manifest.json` แล้วเพิ่ม origin เดียวกันนั้นลงใน `host_permissions`
   (แทน หรือเพิ่มจาก `http://localhost:8000/*`)
3. กลับไป `chrome://extensions` แล้วกด **Reload** ที่การ์ดของส่วนขยาย

> `config.js` ไม่เก็บความลับใด ๆ — เก็บแค่ปลายทาง backend เท่านั้น
> ถ้าต้องการค่าเฉพาะเครื่องโดยไม่ให้ git จับ ให้ใช้ไฟล์ `extension/config.local.js`
> (ถูก ignore ไว้แล้ว) เก็บสำเนาที่แก้เอง

## ขอบเขตสิทธิ์ (permissions)

- `cookies` + `host_permissions` เฉพาะโฮสต์ Aztek — อ่านคุกกี้ได้เฉพาะของ Aztek
- `content_scripts` แทรกเฉพาะหน้า Aztek เพื่ออ่าน localStorage ของหน้านั้น
- ส่วนขยายส่งข้อมูลไปยัง `BACKEND_ORIGIN` เท่านั้น และส่งเมื่อคุณกด "เชื่อมต่อ" เอง

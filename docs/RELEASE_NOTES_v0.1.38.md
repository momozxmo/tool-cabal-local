# All for Cabal Web v0.1.38 — เลือกเบราว์เซอร์จาก Launcher

- เพิ่มช่อง `เปิดเว็บด้วยเบราว์เซอร์` ให้เลือก Default ตาม Windows, Google Chrome, Microsoft Edge หรือ Mozilla Firefox
- จำเบราว์เซอร์ที่เปิดสำเร็จล่าสุด ใช้ต่อเมื่อเปิดโปรแกรมครั้งถัดไปหรือกด shortcut ซ้ำ
- หาโปรแกรมจากทะเบียน Windows และตำแหน่งติดตั้งมาตรฐาน รองรับการติดตั้งนอกตำแหน่งปกติ
- ขอสิทธิ์เข้าเว็บใหม่ทุกครั้งที่เปิดจาก Launcher โดยไม่ทำให้ session ในเบราว์เซอร์อื่นหมดอายุ
- ถ้าไม่พบหรือเปิดตัวที่เลือกไม่ได้ จะแจ้งให้เลือกใหม่ ไม่เปิด Default แทนเอง
- คง Bundle Recheck และการกรอกเรท RANDOM จากรุ่นก่อน

ตัวเลือกนี้ใช้เปิดหน้า All for Cabal เท่านั้น งานอัตโนมัติบน Aztek ยังใช้ Chromium ที่รวมมากับ Setup ตามเดิม
ร่าง/คิวที่เก็บในเบราว์เซอร์เดิมไม่ย้ายไปเบราว์เซอร์ใหม่ ตรวจหรือสำรองงานก่อนเปลี่ยน

ผู้ใช้ v0.1.31 ขึ้นไปกด “อัปเดตโปรแกรม” → “ตรวจอัปเดต” → “อัปเดต” เมื่อพร้อม โปรแกรมจะเปลี่ยนรุ่นเมื่อผู้ใช้เลือกอัปเดตเอง

ทดสอบอัตโนมัติ 1,662 รายการผ่าน และตรวจ health, Local session, ทุกหน้าเครื่องมือ และเปิด shortcut ซ้ำจากแพ็กเกจจริงด้วย runtime แยกผ่าน
Chrome/Edge ตรวจเว็บจริงแบบ headless แล้ว; Firefox ตรวจการเรียก executable ด้วยชุดทดสอบ ยังไม่ได้ลองตัวจริงบนเครื่องนี้
